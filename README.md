# 🍵 Joe Infusi — Sito E-commerce Simulato

Progetto realizzato durante il corso **Full Stack Web Developer** di [Aulab](https://aulab.it), con specializzazione in **Cybersecurity**.

## 🌐 Demo live
[Visita il sito](https://giovannibellanova.github.io/sito-vendita-te/)

## 📋 Descrizione
Sito e-commerce simulato per la vendita di tè e infusi, con focus su **design** e **responsive design**.

## 🛠️ Tecnologie utilizzate
- HTML5
- CSS3
- Bootstrap 5
- Font Awesome
- Google Fonts

## ✨ Funzionalità
- Navbar fissa con dropdown menu
- Header con video in background
- Sezione prodotti con immagini e modal
- Carousel di immagini
- Accordion annidato
- Form di contatto
- Design completamente responsive (mobile, tablet, desktop)
